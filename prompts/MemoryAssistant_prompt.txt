### TASK: CLASSIFY, THEN MERGE LESSONS

These two lessons were retrieved as semantically SIMILAR. Similar is not the
same as compatible: "always do X" and "never do X" are highly similar texts that
cannot both be followed. Decide which case this is BEFORE merging.

Existing: {{existing_lesson}}
New: {{new_lesson}}

Classify as exactly one:
- SAME - they state the same guidance; one is a rephrasing, a subset, or a
  narrower instance of the other.
- COMPLEMENTARY - they address the same topic and add DIFFERENT details that
  can all be followed at once.
- CONTRADICTORY - following one means violating the other. This includes: one
  prescribes what the other forbids; they give different values for the same
  choice (which construct, which variable, which bound); or one asserts a cause
  the other rules out. Judge by whether both can be obeyed, NOT by how
  differently they are worded.

Then:
- SAME or COMPLEMENTARY -> merge into ONE brief sentence that keeps every
  distinct piece of guidance from both.
- CONTRADICTORY -> do NOT merge and do NOT choose between them. Emit no merged
  text; the system resolves the conflict by verified outcome, not by wording.

Output EXACTLY these lines and nothing else:
VERDICT: <SAME|COMPLEMENTARY|CONTRADICTORY>
MERGED: <the merged sentence, or the word NONE when CONTRADICTORY>

### TASK: CLASSIFY, THEN MERGE MODELING CONVENTIONS

Modeling conventions are BINDING encoding decisions for one Alloy 6 model. These
two were retrieved as semantically similar, which is not the same as compatible:
a convention and the convention that REPLACES it read almost identically, because
they are about the same part of the model. Decide which case this is BEFORE
merging - merging a rule with its own replacement produces one sentence that
tells the model builder to do two incompatible things.

Existing convention: {{existing_convention}}
New convention: {{new_convention}}

Classify as exactly one:
- SAME - one is a rephrasing, a subset, or a narrower instance of the other. No

- COMPLEMENTARY - they constrain the same topic in ways that can ALL be obeyed

  weakens a rule the other states absolutely ("in all subsequent states" vs

  ("is now", "no longer", "instead of", "eliminate"). Judge by whether both can
  be obeyed as written, NOT by how differently they are worded.

Then:
- SAME or COMPLEMENTARY -> merge into ONE convention, obeying all of:

  verified outcome decide which survives - so a wrong guess here is expensive

Output EXACTLY these lines and nothing else:
VERDICT: <SAME|COMPLEMENTARY|CONTRADICTORY>
MERGED: <the merged convention, or the word NONE when CONTRADICTORY>
